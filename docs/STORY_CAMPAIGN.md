# 신성 디펜스 v0.9.7 — 스토리 캠페인

## 게임 흐름

6개 난이도마다 고유한 서사·등장인물·도입·결말이 있습니다. 현재 맵 선택과는 별개로 난이도에 맞는 이야기가 진행되며, 맵·적 데이터·밸런스는 변경하지 않습니다.

| 난이도 | 챕터 | 대화 발생 웨이브 |
|---|---|---|
| 쉬움 | 작은 별의 첫걸음 | 1, 3, 5, 7, 9, 10 |
| 기본 | 파수꾼의 마지막 편지 | 1, 4, 7, 10, 13, 16 |
| 어려움 | 강철 심장의 반란 | 1, 4, 8, 12, 18, 22 |
| 익스트림 | 불꽃 아래 흐르는 강 | 1, 5, 9, 14, 21, 28 |
| 지옥 | 잿빛 왕관의 주인 | 1, 6, 12, 18, 27, 34 |
| 파멸 | 세계의 마지막 별 | 1, 7, 15, 23, 32, 40 |

### UI 사용법

1. 로비에서 난이도를 바꾸면 오른쪽 게임 설정 패널의 **스토리 캠페인 미리보기**가 즉시 변경됩니다.
2. **스토리 보기**에서 이미 경험한 웨이브의 전체 대화를 확인하고 이후 장면은 잠금 처리된 목록으로 확인할 수 있습니다.
3. 솔로 또는 협동전에서 해당 웨이브가 시작되면 **캐릭터가 대화하는 비모달 통신창**이 나타납니다. 전투는 그대로 진행되고 별도의 타이머나 네트워크 통신이 발생하지 않습니다.
4. 자동 대사 전환(약 5초), **다음**, **건너뛰기**, **↺ 최근 대사**, **N 키**를 지원합니다. **대사 켜짐/꺼짐** 버튼을 누르면 다음 자동 대사부터 표시 여부를 바꿀 수 있습니다.
5. 전투 중 **✧ 이야기 기록**을 눌러 지난 대사를 다시 열람합니다. 결과 화면에서는 난이도별 성공/실패 에필로그가 출력됩니다.
6. 잠금 해제된 장면은 같은 브라우저의 `localStorage`(`shinsung.story.archive.v1`)에 난이도별로 기록됩니다. 대사 표시 설정도 `shinsung.story.enabled`에 저장됩니다.

### 성능 및 멀티플레이 안정성

- 모든 대사·음영·해금 상태는 브라우저에서만 처리합니다. Cloudflare Worker, Durable Objects, D1, Firebase에 **새 API 호출·동기화·쓰기 요청 없음**.
- 기존 결정론적 `engine.js` 전투 로직과 보상·타워 밸런스에는 어떤 변경도 필요하지 않습니다.
- PvP는 경쟁의 가독성과 공정성을 위해 대화창·스토리 조작 버튼을 표시하지 않습니다. 협동전에서는 각 플레이어 브라우저에서 독립적으로 렌더링합니다.
- 대화 UI는 매 프레임 재생성되지 않고 실제 대사 교체 시에만 DOM을 갱신합니다. 웨이브 진행률 바는 기존 HUD 갱신 주기(약 150ms)를 재사용합니다.
- 저장은 웨이브가 바뀌었을 때만 진행합니다. 인터넷 없이 로컬 모드로 진행한 기록도 기기에 남습니다. **기기 간 스토리 기록 동기화는 지원하지 않습니다.**
- 모바일 좁은 화면 및 `prefers-reduced-motion` 접근성 설정에서 표시 밀도와 애니메이션을 조절합니다.

검증: `npm test` 및 `node scripts/browser-smoke.mjs` (Playwright Chromium 설치 후). 자동 테스트는 모든 6개 캠페인의 실제 마지막 웨이브 번호 일치, 스포일러 보호, 대화 표시·버튼 조작·기기 기록 보존과 전투 UI를 확인합니다.

## v0.9.10: 대화 캐릭터 초상화

모든 등장인물은 실제 게임에 존재하는 타워입니다. 스토리의 캐릭터 ID를 `TOWERS`에 연결하여 대화창의 이름·역할을 해당 타워와 일치시키고, 도감/전투에서도 사용 중인 `character(id)` SVG를 대화창에도 **그대로 재사용**합니다. 게임 캐릭터와 상관없는 이미지/이모지나 외부 요청은 사용하지 않습니다. PC·모바일에서 장면이 넘어갈 때 타워 초상화가 함께 변경됩니다.
