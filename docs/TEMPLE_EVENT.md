# 파멸의 신전 — 독립 이벤트 (v0.11.0)

## 이벤트 규칙

- 이벤트 ID: `temple_of_ruin`, 이벤트 전용 맵: `temple_ruin`
- **30개 전용 웨이브**, 독립 몬스터 8종 (`temple_acolyte`, `temple_knight`, `temple_spore`, `temple_priest`, `temple_guardian`, `temple_colossus`, `temple_oracle`, `temple_deity`)
- 체감 난이도: 익스트림~지옥 정도. 이벤트 몬스터는 강하지만, 시작 자금 **4,200**과 길고 나란히 접힌 신전 복도, 높은 웨이브 보너스가 이를 상쇄
- 신전 주요 적: 10웨이브 **고대 수호체**, 16/20/25웨이브부터 **파멸의 거수**와 신관의 복합 공격, 최종 30웨이브 **신전의 파멸신**
- 정규 게임의 6개 난이도나 5개 추가 모드의 별칭이 아닙니다. 이벤트는 `config.eventId`로 선택됩니다. 정규 맵/난이도/추가 모드는 이벤트에서 사용할 수 없습니다.

## 입장 방법

1. 왼쪽 사이드바의 **☼ 파멸의 신전**을 선택합니다.
2. 전용 맵, 몬스터 8종, 최초 클리어 보상 **고대의 신**을 미리 볼 수 있습니다.
3. **솔로 신전 입장**을 선택하면 브라우저가 실시간 전투를 처리합니다.
4. **친구와 신전 공략 · 협동전**을 선택하면 이벤트 전용 공개 대기실에서 2~4명의 친구가 참가할 수 있습니다. 공개방 및 6자리 코드 초대 지원.
5. 일반 PvP와 이벤트 PvP는 지원하지 않습니다. 일반 협동전 방 목록과 이벤트 협동전 목록은 별도로 필터링됩니다.

## 최초 클리어 보상

**신화 타워 고대의 신** (타워 ID `oldgod`)을 계정에 영구 지급합니다.

- 상점 구매 불가능, 최초 클리어 영구 해금, 재클리어 시 일반 코인/경험치 보상만 중복 지급
- 기준 설치비 8,500, 넓은 사거리 560, 폭발 범위 170, 보스 특화 공격, 타워 최대 1기
- 전용 신벌 공격 `judgement`: 황금/붉은 두 빛기둥, 광역 폭발, 보스 추가 피해 및 다중 충격파
- 진화: **찬란한 후광 → 붉은 오염의 심장 → 종말을 초월한 신**
- 디자인: 사용자 첨부 참조 이미지에서 흰색 거체, 귀·뿔, 금빛 후광, 거대한 황금 팔, 붉은 핵, 유기적인 오염 육체, 헤진 의복을 추출해 전용 인게임 SVG로 직접 제작. 외부 이미지 다운로드 없음.

## 서버 비용과 계정 데이터

- 로그인 솔로 전투 자체는 브라우저의 결정론적 엔진만 사용하고 서버에 3초 간격 신호나 DO 방을 만들지 않습니다.
- 이벤트 **종료 시 `soloReward` 1회** 요청으로 게임 결과를 D1 프로필에 기록합니다. Worker는 클라이언트에서 보낸 코인/XP 숫자를 신뢰하지 않고 서버의 이벤트 편성과 보상 규칙으로 값을 계산합니다.
- 일시적인 네트워크 오류는 기존 미정산 영수증 큐에 보관하고 재로그인 시 재정산합니다. `runId`를 이용한 D1 CAS로 중복 지급을 막습니다.
- 이벤트 협동전은 기존 Cloudflare DO 권위 서버로 진행하고 종료 시 `claim` 액션에서 보상을 영구 저장합니다. 유저마다 같은 방 보상을 중복 수령할 수 없습니다.
- 이벤트 맵 클리어는 일반 5개 맵 탐험 실적 및 기본 난이도 클리어 실적으로 계산하지 않습니다.
