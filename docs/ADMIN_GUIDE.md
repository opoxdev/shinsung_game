# 신성 디펜스 관리자 패널

## 접근 권한

- 관리자 계정: `joehw0405@gmail.com`
- Firebase ID 토큰의 서명·발급자·프로젝트·만료를 확인한 뒤, **이메일 주소가 일치하고 email_verified=true일 때만** Cloudflare Worker에서 관리 권한을 부여합니다.
- 최초 로그인 후 아직 이메일 인증이 되지 않았다면 **계정 관리 → 인증 메일 보내기 → 이메일 링크 클릭 → 인증 완료 확인**을 진행합니다.
- 인증이 끝나면 좌측 메뉴에 **⚙ 관리자 패널**이 나타납니다. 임의로 화면을 조작해 탭을 열어도 모든 관리 API는 서버에서 재검증합니다.

## 주요 기능

- 유저 검색(닉네임, Firebase UID), 총 유저 수·제재 유저 수·총 보유 코인 현황, 프로필 상세 및 페이지 이동
- 계정의 코인·경험치를 양수/음수로 조정, 개별 타워 지급/회수
- 관리자 자기 계정에 테스트 코인 50,000 추가, 모든 타워 해금
- 계정 이용 제한 및 해제. 제재 시 기존 PvP/협동전 룸에서 강제 퇴장 요청을 보내고 서버 프로필의 방 점유를 정리합니다.
- Worker, D1, DO 방 목록 진단, 최근 30개 관리자 변경 감사 기록

## 안전 장치

- 관리자와 일반 사용자 모두 변경 전 확인 대화상자를 확인해야 합니다.
- 모든 사용자 계정 변경은 D1의 version 비교-and-set 방식으로 수행하며 음수 잔액·정수 범위 초과는 거부합니다.
- 자기 자신에게 제재를 적용할 수 없으며, 전체 해금 기능은 관리자 본인에게만 사용할 수 있습니다.
- 모든 관리 변경은 `admin_audit` 테이블에 추적합니다. 기존 D1 배포에는 없으므로 첫 관리 요청에서 자동 생성됩니다. 감사 기록 저장에 실패하면 경고가 표시됩니다.
- 실제 전투 진행 중인 타워·재화는 서버가 관리합니다. 컬렉션 변경은 진행 중인 매치의 전투 스냅샷에 소급 적용되지 않습니다.

## 성능 점검 (v0.9.5)

- 온라인 전투 heartbeat는 Canvas 렌더링과 별도의 약 0.9초 주기로 전송됩니다.
- UI는 서버 원본을 수정하지 않고 **복제된 클라이언트 표시용 예측 상태**로 적 스폰과 이동·웨이브 카운트다운을 갱신합니다. 서버가 도착하면 최신 스냅샷으로 보정합니다.
- 로컬 및 브라우저 회귀 검사: `npm test` 그리고 `npm install --no-save playwright && npx playwright install chromium && node scripts/browser-smoke.mjs`
- 운영 서버의 실제 두 계정·다중 접속 부하와 Chrome/Android/iOS의 FPS는 별도 현장 검증이 필요합니다.
