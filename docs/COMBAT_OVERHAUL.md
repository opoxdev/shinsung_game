# v0.12.0 — 전투 성능·타워 밸런스·적 외형·HUD

## 성능

기존 전투 렌더링은 데스크톱에서 22ms, 모바일에서 34ms를 기다린 뒤 그렸습니다. 60Hz 화면에서는 다음 프레임까지 건너뛰어 각각 약 30fps/20fps가 됩니다. 전투는 이제 매 requestAnimationFrame마다 그리며 50ms 고정 전투 판정과 이동 보간은 유지합니다.

- 적 몸체는 종별로 한 번 그려 ImageBitmap으로 보관합니다. 지원하지 않는 브라우저에서는 캔버스로 대체합니다. 체력·보호막·상태 효과는 별도로 갱신합니다.
- 타워 SVG도 최초 로드 때 래스터 이미지로 변환하여 반복적인 SVG 렌더링을 줄입니다.
- 경로 구간 길이와 단계별 타워 능력치를 캐시합니다. 단일 타깃과 연쇄 타깃은 전체 정렬 대신 선형 탐색합니다.
- 전투 중 툴팁 갱신은 150ms 간격이며, 피해 숫자는 필드당 최대 24개만 그립니다. 간소 효과에서는 피해 숫자를 숨깁니다.
- 축소 상태에서는 적 이미지의 반복 필터링을 생략하고, 확대 상태에서는 부드러운 이미지 필터링을 사용합니다.

동일한 로컬 Headless Chromium / 1280×800 비교:

| 측정 | 이전 | 변경 후 |
|---|---:|---:|
| 실제 전투 그리기 간격 중앙값 | 33.4ms | 16.7ms |
| 적 100마리 렌더 호출 p95 | 148.2ms | 8.3ms |
| 적 350마리 렌더 호출 p95 | 120.5ms | 16.9ms |

`scripts/combat-perf.mjs`로 재현할 수 있습니다. 합성 장면의 Canvas 명령 제출 시간이며, 사용자의 GPU·브라우저·네트워크에서 같은 FPS를 보장하는 수치는 아닙니다. 최초 종별 이미지 생성은 준비 구간에 포함하고 측정 구간에서 제외했습니다. 실제 다인전의 네트워크 지연은 별도 검증이 필요합니다.

## 밸런스

설치 가격·강화 비용·적 체력·웨이브는 유지합니다.

- 일반 공격/소환 타워: 피해 +35%, 공격 간격 ×0.92, 사거리 +8%. 지속 화력 약 +46.7%.
- 근접 기본 유형 타워: 피해 +45%, 공격 간격 ×0.92, 사거리 +12%. 지속 화력 약 +57.6%.
- 지속 피해도 +35%, 지원 오라의 증가분 및 수입 +20%. 단계별 고정 수입/지원 수치에도 적용합니다.
- 고대신: 피해 ×0.88, 공격 간격 ×1.04. 지속 화력 약 -15.4%. 사거리·보스 추가 피해·범위·설치 제한 유지.

클라이언트와 Worker가 같은 데이터를 빌드하여 사용합니다. 캠페인 전체 승률을 자동 튜닝한 결과가 아닌 첫 밸런스 조정이며, 장기 플레이 결과를 보고 후속 조정할 수 있습니다.

## 외형과 UI

41종 적의 외형을 좀비·질주형·거수·기계·망령·주술사·신전의 7계열로 정리했습니다. 얼굴 윤곽, 장비, 갑옷, 날개, 지팡이, 왕관, 보호 방패 등을 추가하고 종별 색상과 크기 차이를 유지합니다.

기지 체력 막대/위험 색상, 현재 필드의 가장 큰 보스 체력판, 설치 자금 부족 표시, U 강화, 강화 패널 닫기, 웨이브 정보 펼치기, 효과 표준/간소 버튼을 추가했습니다. 모바일에서 스킵 버튼과 조작 버튼의 겹침을 검사했습니다.
