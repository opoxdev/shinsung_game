# 신성 디펜스 v0.9.1 — 등급별 캐릭터 아트 위계

## 핵심 판단

**개성은 등급마다 있어야 하지만, 희소성은 모든 등급에 똑같이 적용하지 않는다.**

일반이나 희귀가 신화처럼 빛나거나 화려한 동물 가면, 갑옷, 복잡한 냉기 마법진과 거대 드론을 쓰면 전설·신화를 보유하고 싶어지는 동기가 사라진다. 그러나 모두 똑같은 군복과 헬멧을 씌우면 캐릭터 자체의 인상이 사라진다.

아래 기준은 외형의 위계다. **배치 비용·후반 성능·진화 단계·등급은 서로 별개**라는 기존 게임 디자인을 유지한다.

| 등급 | 이름과 콘셉트 | 기본 실루엣과 디테일 | 연출 |
|---|---|---|---|
| 일반 | 새총잡이, 궁수, 투척병, 포수 | 평범한 머리·옷·작업 도구, 소박한 재료와 무기 | 신비로운 후광·왕관·가면 금지 |
| 희귀 | 전기공, 검객, 약제사, 서리 견습생, 드론 조작원, 사냥꾼, 관측원 | 단일 전문 소도구와 약간의 개성. 전문성은 보이지만 대단한 영웅처럼 보이지 않음 | 작은 색상 악센트·장비 개선만 허용 |
| 에픽 | 폭파 전문가, 고블린 소환사, 버섯 정원, 화염술사, 달빛 기사, 번개 발명가, 시계 장인, 황금 공방, 산호 연주자, 음향 조율사 | 각 유닛 고유 장비·비대칭 소품·직업별 색상·몸 형태 | 제한된 주제별 마법/장비 장식 |
| 전설 | 별술사, 프리즘 마법사, 낫 든 토끼, 폭풍 사제, 종이학 조련사 | 장비와 외곽 장식에서 명확히 기억되는 특수 실루엣 | 별·프리즘·낫·폭풍·종이학 별도의 큰 동작 |
| 신화 | 소닉, 불사조 조련사, 오로라 정령, 별씨앗 | 서로 겹치지 않는 독자적인 주제 형상 | 콘서트 음파·불사조 날개·오로라 리본·궤도 씨앗 |

## 실제 구현 구조

- `src/visual-design.js`의 **일반·희귀 기본 외형은 장비별 손그림 SVG**(`everydayPortrait`)을 사용한다. 이 11종의 기본 모습에는 동일한 전술 헬멧·방탄복·거대 장비를 반복하지 않는다.
- 에픽·전설·신화는 `prestigeBack` / `prestigeFront`로 클래스별 장식을 생성하며 각각의 상징물 위치와 형상이 다르다.
- `src/art.js`에서 일반·희귀의 강화 단계는 **각 직업에 맞는 도구·의상·조준기·탄약통·지팡이·소형 드론**으로만 변한다. 강제로 왕관이나 날개를 추가하지 않는다.
- `src/game.css`의 컬렉션 카드도 일반·희귀는 저채도, 에픽은 중간, 전설·신화는 명확한 광원·테두리로 위계를 만든다.
- `data-art-tier` SVG 속성은 `everyday / craft / specialist / iconic / myth`로 각 등급의 기본 외형을 표시해 테스트할 수 있도록 했다.

## 상점·진화·획득은 보존

타워 내부 ID 30종, 공격/소환/지원 메커니즘, 배치비, 상점 코인, 기존 보유 기록, 도전 보상, 업그레이드 효과, 맵과 멀티플레이는 변경하지 않는다. 예를 들어 희귀 사냥꾼은 높은 비용의 후반 저격 타워이지만 기본 외형은 낡은 긴 총과 외투의 평범한 사냥꾼이다. 초반형 신화 별씨앗은 값이 싸더라도 소장할 만한 고유 형상을 유지한다.

강화 이름과 효과는 별개다. 특수 공격이 추가되어도 기본 타워가 무조건 화려한 이벤트 캐릭터로 변신할 필요는 없다.

## 스킨이 희소성의 별도 축

스킨은 해당 타워의 기본 실루엣에서 **복장과 머리·무기·장식 전체가 바뀌는 수집형 모습**이다. 모든 스킨을 모든 유닛에게 적용하지 않는다. 제작 대상은 `SKIN_STYLES[style].targets`로 제한된다.

- `chef`의 일반 **투척병** → 전설 `donut` 스킨 **도넛 요리사**.
- `blade`의 희귀 **검객** → 신화 `kitsune` 스킨 **구미호 가면검객**.

반짝 의상 상자는 1,000코인, 천상의 별빛 상자는 5,000코인으로 기존 가격을 유지한다. 전체 상자 가격, 확률 시스템, 중복 처리 및 이전에 획득한 스킨의 장착 가능 여부는 유지한다. 스킨은 공격력 등 전투 성능을 올리지 않는다.
