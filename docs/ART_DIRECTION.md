# 신성 디펜스 v0.8 — 캐릭터·스킨 아트 디렉션

## 목적

로블록스 타워배틀·타워 디펜스 장르의 **명확한 병과 실루엣**, 등급별 장비 밀도, 스킨의 독립적인 코스튬이라는 구조를 참고한다. 특정 게임의 캐릭터 모델·애니메이션·디자인을 복제하지 않으며, 자체 제작된 SVG 형상만 사용한다.

- **일반:** 정찰병, 정밀 사수, 수류탄병, 중화기병. 전투복·발사기·석궁·수류탄·중화기 중심. 무조건 저렴하거나 초반 전용인 등급은 아니다.
- **희귀:** 전격병, 검술병, 독성 연구원, 냉각병, 드론 운용병, 특수 저격수, 표식 사수. 전문 무기와 장비의 차이로 구분한다. 일상적인 기본 외형에는 동물 가면·축제 연출·왕관을 붙이지 않는다.
- **에픽:** 고블린 소환사, 균사형 버프 시설, 폭파 전문가, 화염술사, 달빛 기사, 전기 기술자, 시계 장인, 보급 기지, 산호 연주자, 음향 지원병 등. 전술 기술과 판타지가 혼합될 수 있지만, 목적이 보이는 장비를 사용한다.
- **전설:** 별술사, 프리즘 마법사, 낫 든 토끼, 폭풍 사제, 종이학 조련사. 실루엣·무기 구조와 장식의 복잡도를 강화한다.
- **신화:** 소닉, 불사조 조련사, 오로라 정령, 별씨앗. 충분히 눈에 띄는 초상과 신화적 능력을 허용하되 배치 비용·초중후반 역할과 등급은 별개다.

게임 내 타워 ID 30개, 전투 능력, 상점 코인, 기존 프로필 소유 키는 유지한다. 기존 이름만 바꾸는 것이 아니라 기본 SVG 무기·머리 장비·전투복·몸통 실루엣을 새로 그린다.

## 스킨 제작 원칙

**모든 카테고리를 모든 타워에 적용하지 않는다.** 각각의 `SKIN_STYLES[style].targets`는 실제로 제작한 스킨의 대상 ID다.

스킨은 색상 필터가 아니라 방어복·모자/헬멧·망토·장식·무기의 전체 재구성이다. 신규 제작한 스킨의 15개 테마와 적용 대상은 `src/data.js`에 명시한다. 대상 이외의 타워는 새 상자에서 해당 스킨을 획득할 수 없다.

특별한 콘셉트 두 가지를 기본 타워에서 분리한다.

- **도넛 요리사:** 기본 `chef`는 일반 등급 **수류탄병**, 도넛 모자·앞치마·도넛 폭탄 등은 전용 `donut` 전설 스킨으로만 등장한다. 반짝 의상 상자에서 획득 가능.
- **구미호 가면검객:** 기본 `blade`는 희귀 등급 **검술병**, 가면·한복형 외투·꼬리 장식·검은 전용 `kitsune` 신화 스킨으로만 등장한다. 천상의 별빛 상자에서 획득 가능.

`src/visual-design.js`에서 원본 인물 30종과 착용 스킨별 독립적인 SVG를 생성한다. `src/art.js`는 진화 단계별 장비를 추가하고, `src/render.js`는 전투 캐릭터·드론 등 실제 소환수 외형을 그린다. 낮은 등급의 진화는 실용 장비 추가이며 높은 등급에서는 특수 장비와 이펙트를 허용한다.

## 스킨 상자와 계정 데이터

- 스킨 상자 비용: 비밀의 숲 400 / 반짝 1,000 / 빙설 1,500 / 네온 3,000 / 천상 5,000 코인. 10회 개봉은 가격의 10배.
- 각 상자 확률 표의 가중치 합은 100이다. 실제로 출현 가능한 스타일은 **플레이어가 소유하고 있고 해당 스킨의 제작 대상인 타워**에 한정한다.
- 따라서 UI는 그 계정에서 당장 획득 가능한 스타일만으로 가중치를 재정규화한 확률을 표시한다. 신규 타워를 영입하면 표시 확률도 달라진다.
- 10연속 중복 보장 발동 시에는 미보유 스킨으로 출현 풀이 다시 제한된다. 이는 일반 개봉 확률과 별도로 표기한다.
- 스킨은 외형 전용이며 전투 능력치와 공격 메커니즘을 변경하지 않는다.
- **기존 보유 스킨 보존:** 과거에 획득한 `towerId:skinId`는 현재 대상 목록 밖이어도 장착 및 렌더링을 계속 허용한다. 기존 데이터 삭제나 환급 강제 전환은 없다.
