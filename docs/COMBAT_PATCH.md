# 전투 화면·조작·부드러움 패치

- 맵 바깥에 같은 테마의 지형을 420만큼 확장했습니다. 카메라 이동·축소 한계를 화면 비율에 맞춰 계산해서 빈 배경이 드러나지 않습니다. PvP 두 필드도 지원하며, 실제 배치 영역·경로·밸런스는 그대로입니다.
- E를 누르고 있으면 확대, R은 축소합니다. 휠과 기존 버튼도 지원합니다.
- 타워 설치가 성공하면 설치 모드를 종료합니다. 설치 불가/자금 부족 시에는 선택이 유지되고, Q/우클릭으로 취소할 수 있습니다. 온라인은 서버 성공 응답을 기준으로 종료합니다.
- 로컬의 20Hz 전투 판정 사이를 화면 프레임별로 보간합니다. 온라인 위치 보정은 점진적으로 적용하며, 감속/돌진 종료 시각을 반영합니다. 재연결 중 예측은 기존처럼 최대 2.2초로 제한합니다.
- 화면 밖 캐릭터를 생략하고, 캔버스 크기는 실제 크기 변경 때 갱신합니다. 픽셀 밀도는 최대 1.5로 제한하고, 지형·캐릭터 이미지를 재사용합니다. 변경 없는 HUD 텍스트를 다시 쓰지 않습니다.
- 상단 상태판, 하단 타워 카드, 스킵 버튼, 강화 패널을 줄였습니다. 작은 화면과 낮은 화면에서도 별도로 배치합니다.

## 확인

- `npm test`: 71개 통과. 화면 비율/PvP 카메라 경계, 경로 모서리 보간, 원본 전투 데이터 불변, 온라인 보정, 상태 효과 만료 및 정지 처리를 포함합니다.
- Chromium: 1848×950 및 390×844에서 조작/배치/카메라와 빌드 실행 확인. 페이지 오류 0건.
- 실제 계정으로 다중 클라이언트 온라인 전투 및 사용자 기기의 FPS 측정은 수행하지 않았습니다. 서버 주기/네트워크 비용은 바꾸지 않았습니다.

## 적용

소스를 반영한 뒤 `npm run build`로 결과물을 새로 생성하고 기존 Cloudflare 배포 절차를 실행합니다. `dist`의 이전 체크인 파일을 그대로 업로드하지 마세요. 이 패치는 GAS 접속 셸·Firebase 설정·D1 스키마 변경이 필요 없습니다.
