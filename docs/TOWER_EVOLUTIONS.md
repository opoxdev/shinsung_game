# 30종 타워 개체별 진화 시스템 — v0.6.0

## 전투 중 진화가 이루어지는 방식

- **타워를 설치**하면 해당 개체에 고유 `id`, `level:0`, `spent`가 생깁니다.
- 전투 중 타워를 클릭하면 진화 패널에서 현재 장비, 다음 단계의 이름, 사거리·피해량·간격 변화, 새 공격 방식, 비용을 볼 수 있습니다.
- 적 처치 또는 웨이브 보너스로 모은 **전투 자금**으로 해당 개체 하나만 강화합니다.
- 동일한 새총소년 5개를 설치한 경우, 1개의 레벨을 올려도 나머지는 그대로입니다.
- 타워마다 최고 단계가 다릅니다. 최고 단계에서는 버튼이 막히고 **서버도 명령을 거부**합니다.
- 판매 시 그 개체의 배치·강화비 총 지출의 70%를 반환합니다. 다른 타워 지출은 합산하지 않습니다.
- 모든 전투 명령은 기존 Cloudflare Durable Object 권위 엔진에서 수행되어 PvP·협동전 규칙도 유지됩니다.

## 등급과 배치 비용은 별개

- **최고 등급은 신화**입니다. 과거 불멸 등급의 오로라 정령은 신화로 편입하며, 보유·진화·파멸+엘리트 클리어 획득 조건은 그대로 유지합니다.
- 일반 타워라고 항상 싸지 않고, 신화 타워라고 항상 비싸지 않습니다. 전투 배치 비용은 **타워의 역할·시기·범위·공격 메커니즘**에 맞추어 독립적으로 정합니다.
- 예시: 신화 「별씨앗」은 배치비 ₩145인 초반 광역 타워이고, 희귀 「밤의 추적자」는 ₩2,200의 후반 보스 저격 타워입니다.
- 전투 자금(₩, 배치·강화)과 상점 코인(영구 소유)은 별개의 재화입니다.

## 품질 보증

`tests/evolution.test.mjs`는 타워 5개의 독립 진화, 지출·최대 레벨, 협동전 소유권, 사격→광역 변환, 소환 증가, 외형 차이를 검사합니다. 기존 엔진/Cloudflare/GAS 빌드 테스트도 유지합니다.

추가로 실전 브라우저에서 2계정 PvP·협동전을 열어 업그레이드 UI, 네트워크 지연, 과도한 타워 배치 시 프레임 유지와 경제 밸런스를 확인해야 합니다.

## 배포

공식 게임 주소는 **Google Apps Script** `/exec`로 유지합니다. GAS `Code.gs` / `Index.html` 최종 작업은 게임 개발 마무리 때 진행합니다. 평소 게임 자산 및 전투 엔진 업데이트는 기존 GitHub → Cloudflare 배포를 활용합니다.
