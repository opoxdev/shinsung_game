# 도전과제 시스템 운영 가이드 — v0.10.0

## 개요

도전과제는 기존 영구 소닉 해금 하나에서 **총 35개**로 확장했습니다.

- **여정(12개):** 첫 승리, 승리 5/20/50회, 6개 난이도 클리어, 서로 다른 맵 3/5곳 클리어
- **전투(5개):** 누적 몬스터 처치 100/1,000/10,000마리, 타워 누적 설치 50/500회
- **전략(8개):** 타워 강화 30/300회, 무피해 클리어, 탱크/엘리트/군사부족 모드 클리어, 소닉·오로라 신화 해금
- **수집(6개):** 타워 보유 5/15/25종, 스킨 3/10개, 몬스터 팩 2종
- **멀티플레이(4개):** PvP 1/5승, 협동 1/5승

## 진행 흐름

1. 사이드바 **✧ 도전 과제**를 눌러 대시보드를 엽니다. 전체 달성률, 보상 수령 수, 남은 보상 수가 표시됩니다.
2. 여정, 전투, 전략, 수집, 멀티플레이 카테고리로 필터링하고 각 목표의 진행률을 확인합니다.
3. 클리어와 전투 지표는 **전투 종료 후 정산할 때** 기록됩니다. 소지 타워/팩/스킨 수는 프로필에서 즉시 계산합니다.
4. 목표를 달성하면 보상 수령 버튼이 활성화됩니다. 누르면 서버가 조건과 중복 수령 여부를 검사한 뒤 코인/XP를 계정에 영구 저장합니다. 게스트는 로컬에 저장합니다.
5. 기존 소닉·오로라 보유자는 해당 신화 도전과제가 자동 수령 완료로 표시됩니다. 신규 이용자의 기존 신화 타워 자동 해금 메커니즘도 유지합니다.
6. 솔로 전투 결과 화면에서 새로운 도전과제가 생기면 안내하고, 도전과제 페이지의 '수령 가능' 필터로 바로 이동합니다.

## 서버 저장/비용

계정의 `achievementStats`와 `claimedAchievements`는 기존 D1 `profiles.profile_json`에 저장합니다. 별도의 신규 테이블이나 정기 스케줄은 없습니다.

- 솔로에서 웨이브, 몬스터 스폰, 공격, 타워 설치, 강화 중에는 **도전과제용 추가 서버 통신 0회**.
- 종료 시 기존 `soloReward` 요청의 `achievementRun`에 `kills/places/upgrades/flawless` 등 숫자만 포함합니다. Worker가 값을 검증·상한 처리하며, 기존 코인/XP 정산과 진행도 기록을 **동일한 D1 CAS 쓰기**로 처리합니다.
- PvP·협동전에서 `reward` API가 서버 권위 게임 상태로 진행도 요약을 계산하여 기존 정산 API에서 함께 저장합니다. 라이브 동기화 패킷이나 WebSocket 핑 빈도는 변경하지 않습니다.
- 도전과제 수령은 클릭당 1회 서버 요청입니다. 중복 수령을 시도해도 추가 보상이나 D1 쓰기를 하지 않습니다.
- 저장소 크기는 단순 카운터, 완료 맵/난이도/모드별 카운터, 수령한 도전과제 ID 몇 개뿐입니다. 전투 로그나 타워 기록 전체를 프로필에 축적하지 않습니다.

## 기존 플레이어 마이그레이션

기존 `wins`, 보유한 소닉/오로라, 보유 타워/스킨/팩 등 **이미 서버에 있는 기록은 자동 반영**합니다. 과거 개별 난이도 클리어 횟수, 처치 수, 설치 수는 예전 프로필에 없었으므로 가상으로 만들어 주지 않고 업데이트 이후부터 집계합니다.

기존 소닉/오로라 도전의 성공 조건은 각각 **익스트림 이상+슈퍼소닉**, **파멸+엘리트** 그대로 유지합니다.
